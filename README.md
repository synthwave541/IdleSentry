## Installation and updates

Requires macOS 13 or later. Download the universal DMG, open it, and drag IdleSentry to Applications. Both Apple Silicon and Intel are supported. Current builds are ad-hoc signed and not Apple-notarized; see [first-run guidance](FIRST-RUN.txt) and the guide included in the DMG if macOS blocks first launch.

Existing installations can use Check for Updates from About or the menu bar. The signed Sparkle feed stays at `releases/latest/download/appcast.xml`. The ZIP is the updater archive; use the DMG for manual installation. SHA256SUMS.txt covers the DMG and ZIP.
